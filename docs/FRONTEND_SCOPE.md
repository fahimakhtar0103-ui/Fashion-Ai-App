# Frontend milestone

This stage is intentionally frontend-only so the product flow can be reviewed before any paid AI API is connected.

## Current screens
- Home dashboard
- Create Reel
- Templates
- Library
- Settings

## Create Reel inputs
- Product photos
- Garment category
- Reel template
- Draft / Standard / Premium quality
- Product name / SKU
- Price
- CTA / note

## Template library
The first frontend includes 16 starter template concepts covering premium, catalogue, bridal, festive, offer, studio, runway, close-up, arrival and story formats.
